# CartPilot
CartPilot是小红书商城新增功能：Agentic人工智能买手的demo。通过自动分析用户浏览和搜索行为，在给定的预算和推荐频率下，CartPilot将自动为用户生成购物车，并提供不同风格和要求下的备选，极大简化了用户的种草-下单流程。

> ## 一、解决的问题

在内容社区里，用户的购买意图往往已经非常明确，但从"被种草"到"真正下单"之间仍然存在一段**高摩擦链路**：

- 用户要自己回忆看过哪些笔记、想买什么；
- 要在多个品牌之间比较；
- 要控制预算、凑齐购物车；
- 还要在"买/不买"之间反复犹豫。

结果是：**购买意图没有被及时转化，种草也停留在收藏夹**，购物决策成本长期由用户自己承担。小红书完成了种草和消费需求的激活，但其它电商平台可能这段消费需求的损耗链任何一环趁虚而入。

CartPilot 把推荐系统从"给出若干单品"升级为替用户完成一段从意图识别到选品组合全程agentic，用户仅需完成下单操作。

## 二、核心特性

- **预算驱动**：用户设定推荐频率（每天 / 每周 / 每月）和预算上限（¥200 – ¥1200），CartPilot 在 30+ 商品池里自动选品组装，目标价位贴近预算上限。
- **多模式自动装车**：四档购买模式 —— 实用 / 品牌 / 颜值 / 性价比，每种模式下选品权重不同。
- **多套买手方案**：点"刷新购物车"在当前预算约束下循环出不同组合，不会卡死在同一套方案。
- **可解释的信号面板**：展示 CartPilot 为什么这样拼 —— 中古/法式 88、敏感肌修护 81、品牌质感 74、通勤场景 63 等加权信号。
- **逐件可替换**：每件商品下方横向滚动 6 个替代方案（同价位 / 更便宜 / 升级款 / 风格外扩 / 形态替代），点"换成这件"即时替换，预算条同步更新。
- **用户权限**：保留用户最终下单权，把"选品 / 比价 / 凑单 / 替代决策"压缩成一次从上往下的确认。
- **可交互内嵌 demo**：营销页底部嵌入了一台手机大小的真机框，可直接体验从拼车到下单的完整流程。
- **深色模式**：跟随系统主题，可手动切换。
