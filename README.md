# CartPilot
CartPilot是小红书商城新增功能：Agentic人工智能买手的demo。通过自动分析用户浏览和搜索行为，在给定的预算和推荐频率下，CartPilot将自动为用户生成购物车，并提供不同风格和要求下的备选，极大简化了用户的种草-下单流程。
> RFT · 小红书 Red Finance Trainee · Builder Test 48h Demo
> Live Demo: **[https://auracui01.github.io/CartPilot/](https://auracui01.github.io/CartPilot/)**
## 一、解决的问题

在内容社区里，用户的购买意图往往已经非常明确，但从"被种草"到"真正下单"之间仍然存在一段**高摩擦链路**：

- 用户要自己回忆看过哪些笔记、想买什么；
- 要在多个品牌之间比较；
- 要控制预算、凑齐购物车；
- 还要在"买/不买"之间反复犹豫。

结果是：**购买意图没有被及时转化，种草也停留在收藏夹**，购物决策成本长期由用户自己承担。小红书完成了种草和消费需求的激活，但其它电商平台可能这段消费需求的损耗链任何一环趁虚而入。

CartPilot 把推荐系统从"给出若干单品"升级为替用户完成一段从意图识别到选品组合全程agentic，用户仅需完成下单操作。

## 二、核心特性

- **预算驱动**：用户设定推荐频率（每天 / 每周 / 每月）和预算上限（¥200 – ¥1200），CartPilot 在 30+ 商品池里自动选品组装，目标价位贴近预算上限。
- **多模式自动装车**：四档购买模式 —— 实用 / 品牌 / 颜值 / 性价比，每种模式下选品权重不同。
- **多套买手方案**：点"刷新购物车"在当前预算约束下循环出不同组合，不会卡死在同一套方案。
- **可解释的信号面板**：展示 CartPilot 为什么这样拼 —— 中古/法式 88、敏感肌修护 81、品牌质感 74、通勤场景 63 等加权信号。
- **逐件可替换**：每件商品下方横向滚动 6 个替代方案（同价位 / 更便宜 / 升级款 / 风格外扩 / 形态替代），点"换成这件"即时替换，预算条同步更新。
- **用户权限**：保留用户最终下单权，把"选品 / 比价 / 凑单 / 替代决策"压缩成一次从上往下的确认。
- **可交互内嵌 demo**：营销页底部嵌入了一台手机大小的真机框，可直接体验从拼车到下单的完整流程。
- **深色模式**：跟随系统主题，可手动切换。

## 三、Demo 操作指南

打开 [https://auracui01.github.io/CartPilot/](https://auracui01.github.io/CartPilot/) 后：

1. 上滑浏览 **痛点 / 功能 / 转化率与粘性预测 / GMV 增长曲线**。
2. 滚动到底部，会看到一台嵌入的手机界面。
3. 在手机内的**偏好条**调整：
   - 推荐频率：每天 / 每周 / 每月
   - 预算上限：拖动滑条（¥200 – ¥1200）
   - 购买模式：实用 / 品牌 / 颜值 / 性价比
4. **拖动预算** → CartPilot 实时重组购物车，slot 数会随预算从 3 件扩展到 5 件，可能命中通勤耳机这种 hero 单品。
5. 点 **更多选择** 中的"换成这件" → 替换单件并自动更新预算条。
6. 点 **刷新购物车** → 在当前预算约束下循环换出不同组合。
7. 点 **确认并下单** → 进入模拟下单成功页。

## 四、技术实现

- 纯 **静态 HTML / CSS / JavaScript**，无构建工具、无后端、无依赖。
- 单页结构 + 内嵌可交互手机模拟器。
- 商品池：30+ SKU 横跨配饰、护肤、通勤、家居、数码 5 类，价位 ¥68 – ¥1280。
- 组车算法：
  1. 按预算决定 slot 数（3 / 4 / 5）；
  2. 给每个 slot 计算目标价位（剩余预算 ÷ 剩余 slot 数，按 variant 偏移 ±25%）；
  3. 综合"价格接近度 + 模式权重 + variant 偏移"打分，从 top 3 中挑选；
  4. 完成后再做一轮 **预算回填** —— 若总价 < 92% 预算，自动升级最贵 slot；若超预算，则降级。
- 替代品生成：每件商品自动派生 6 个替代方案（同价位 / 更便宜 / 升级款 / 风格外扩 / 形态替代）。
- 暗色模式：CSS 变量 + `data-theme="dark"`，首次加载跟随 `prefers-color-scheme`。

## 六、产品思考摘要

CartPilot 的核心不是"推荐一件商品"，而是：

- **从"逛"和"搜"中识别即时购买意图**（搜索词、停留时长、收藏、互动）；
- **在预算和频率约束下完成买手式的购物解决方案**，而不是单点或单品推荐；
- **在高度自动化的同时保留用户的最终决策权**（替换、删除、刷新、approve）；
- **压缩种草到下单之间的损耗，同时以订阅制的方式培养用户粘性**。

在这个过程中，购物决策实现了完全的产品化和agent化，而不是在商品推荐feed的基础上做简单的线性组合。对于时间成本敏感的用户而言，他们需要的不是像刷短视频一样刷几个小时的商品，而是一个AI买手替他们做好自己会喜欢的决策并为之支付。本质上，CartPilot替代的不是推荐算法，而是将传统的线下订阅制/会员制买手店以高效率完成了电商化和AI化。

## 七、数据与假设
**订单转化率**
在线冲动消费的核心机制之一，是平台通过信息技术降低搜索与购买摩擦，从而把“原本可能停留在兴趣层面”的需求更快地转化为实际下单。
​针对在线冲动消费的元分析指出，在线购物环境中，导航、易用性、视觉吸引力、促销、稀缺性以及正向情绪等因素，都会显著推动冲动购买行为；而个性化推荐和 one-click buying 等 IT 支持能力，会缩短购买路径并提升冲动购买发生的可能性。这对 CartPilot 的含义很直接：它并不是再增加一个推荐位，而是把“搜索—浏览—比较—凑单—下单”压缩成一段更短、更顺滑的决策路径。相关研究明确指出，个性化推荐可以优化商品发现过程，而 one-click buying 会让购买路径更短、更容易完成，这两点都会同时提高转化率和冲动购买发生率。
​因而，若 CartPilot 能把高意图内容消费直接转译为可 approve 的购物车方案，那么“订单转化率上升”作为产品假设是有文献依据的。进一步看，2024 年关于 Shopee Video 的研究显示，时间压力、数量压力、经济利益、社交影响、视觉和声音等外部刺激，会通过 arousal（唤醒）与 pleasure（愉悦）影响在线冲动购买。这意味着，在内容电商场景下，只要平台能在用户被内容激发的当下，及时给出低摩擦、视觉上可信、决策成本低的购买入口，就更容易把“情绪高点”转化成下单动作。CartPilot本质上就是在利用这一机制：在兴趣尚未衰减前，把用户从“还在想买什么”直接推到“确认这一车是否下单”。

**复购率**
关于复购率的提升机制不是“冲动消费一定直接提高复购”，而是“在某些电商刺激机制下，冲动购买能够成为复购意向形成的中介路径”。一项针对 TikTok Shop 用户的研究发现，flash sale 与 live streaming 都会显著提升 repurchase intention，而 impulsive buying 在其中发挥了重要作用：其对复购意向具有显著正向影响，并且部分或完全中介了这些刺激机制与复购之间的关系。这说明，冲动购买并不是一次性行为的终点；在内容电商平台上，它也可能成为“用户再次回来买”的起点。原因在于，当用户在低摩擦、情绪驱动、即时满足的购物体验中形成正向反馈后，平台更容易把这种体验固化为新的购买习惯。对 CartPilot 来说，按“每天 / 每周 / 每月”设定的推荐频率、预算上限，以及一键刷新购物车的机制，正是把一次偶发下单改造成“周期性回来看看这周给我拼了什么”的产品节奏。
并非所有促销和直播刺激都能显著提升冲动购买本身，有些研究发现它们对冲动购买的直接作用不显著，但对复购意向仍有正向影响。
